02
SISTEMA FINANCEIRO

FinanceFlow ↗

Sistema de gestão financeira pessoal desenvolvido para centralizar receitas, despesas, contas, investimentos e análises em uma única aplicação. Possui dashboard, transações com filtros e edição, relatórios por período, separação entre patrimônio e investimentos, tema claro/escuro e identidade visual própria.

O projeto também conta com backend em C#/.NET 10, ASP.NET Core Web API, Entity Framework Core, PostgreSQL, Docker e automações do GitHub Actions para gerar uma versão Android baseada em WebView.
